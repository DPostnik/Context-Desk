# Documentation

Tracked files in this directory describe the app, building, architecture, and
delivered improvements. Git keeps their history; edit them in place without
numbered copies or a separate document-version log.

Private research and working documents belong in `docs/private/`, which is
excluded from the main Git repository. Use a stable descriptive filename, such
as `docs/private/research/context-tools.md`, and update the document in place.
Keep the date, sources, status, and validation limitations in the document.

Ignored documents have no history in the main Git repository and are not
included in pushes, fresh clones, or Git-based backups. Do not force-add
private documents, personal usage analyses, or raw chat exports.

Product delivery records remain in the tracked `improvements.md`; private
research recommendations are not evidence of implemented app behavior.
